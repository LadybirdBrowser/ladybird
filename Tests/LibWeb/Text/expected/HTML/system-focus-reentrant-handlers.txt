Window blur handler restores system focus: window.blur, window.focus, original.focus, original.focusin; original input still active=true; document.hasFocus()=true
Window focus handler redirects focus without duplicate events: window.focus, redirected.focus, redirected.focusin; redirected input active=true
Input blur handler focuses iframe without system focus: window.blur; iframe remains active=true; document.hasFocus()=false
System focus returns to iframe: iframe window.focus
Iframe focus handler loses system focus without focusin: iframe window.focus, frame.focus, iframe window.blur; document.hasFocus()=false
